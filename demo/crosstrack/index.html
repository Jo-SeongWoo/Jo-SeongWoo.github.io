클릭으로 할 수 있는 것
🔹 등기번호 클릭 — 그 번호를 복사
🔹 종적 줄 클릭 — 그 사이트(ePOST·GCSS·iCare) 조회 페이지를 백그라운드로 엶
🔹 카드 클릭 — 카드 선택(파란 테두리), 다시 클릭하면 해제. Ctrl+클릭으로 여러 개 콕콕, Shift+클릭으로 처음~끝 한 번에

지우기
🔹 카드의 × — 그 카드 삭제 (모든 탭에서 사라짐. 위 입력칸 글자는 안 지워짐)
🔹 Delete — 선택한 카드 한꺼번에 삭제
🔹 ESC — 선택 해제 (선택한 게 없으면 사이드패널이 닫힘)
❔ 사용설명 ▼
📋 이 탭은? 등기번호 여러 개를 한 번에 붙여넣으면 ePOST·GCSS·iCare 세 곳을 동시에 조회해서, 우편물이 지금 어느 단계에 있는지 한눈에 정리해 줍니다.

① 조회하는 법
🔹 입력칸에 등기번호를 넣고 [조회 시작] (또는 Enter). 여러 개는 줄바꿈·공백·쉼표·세미콜론 아무거나로 구분
🔹 같은 번호가 여러 번 들어가도 자동으로 한 번만 조회 (중복 제거)
🔹 소문자로 써도 자동으로 대문자 처리됩니다
🔹 조회를 시작하면 입력·도움말 영역이 접혀서 결과가 넓게 보입니다. 다시 펼치려면 위쪽 ▼ 버튼

② 카드 한 장 = 우편물 하나
🔹 카드 안에 ePOST / GCSS / iCare 세 줄이 있고, 각 줄은 그 사이트의 가장 최근 종적입니다
🔹 세 줄 중 가장 최근에 움직인 줄이 굵게 표시됩니다 (= 지금 가장 따끈한 정보)
🔹 등기번호 옆 파란 약호(예: BR) = 도착국 (ePOST 기본정보 기준)
🔹 R·L·C로 시작하는 등기는 iCare에 자료가 없어서, iCare 줄이 비어 있음(—)으로 나옵니다. 정상이에요
🔹 카드 순서 — 세 사이트 중 가장 최근 종적 순으로 위에서부터 정렬 (Details검색 탭만 GCSS·iCare 기준)

③ 색 뱃지 (GCSS·iCare 줄 뒤) = 행방조사 최근 단계
🔹 파랑 Q · 청록 R · 보라 SUM·Msg 중 가장 최신을 띄움
🔹 회색 NOT·NQ·NR 은 위 3개가 하나도 없을 때만 (→ '쿼리없음' 분류)
※ 종료(CLOSURE)는 표시 안 함

④ 위쪽 탭 = 단계별 자동 분류
모든 우편물을 진행 단계에 따라 탭으로 나눠 줍니다. 한 우편물에 여러 단계가 있으면 가장 많이 진행된 단계로 분류돼요. (분류는 GCSS 종적 기준, 반송만 ePOST 기준)
🔹 정상 흐름: RD(상대국 도착) → EMD(교환국 도착) → 세관계류(EDB·EME) → 세관탈출(EDC) → 배달시도(EMH) → 정상배달(EMI)
🔹 반송 흐름: EDX(반송 결정) → 반송진행(GCSS·iCare에 반송 dispatch) → 반송도착(ePOST에 반송 종적) → 반송배달(ePOST 반송 + 배달완료)
🔹 기타 = 위 어디에도 안 잡힌 것 + 조회 실패한 것 모음
🔹 쿼리없음 = 행방조사 누락 방지용 (단계와 무관해서 다른 탭에도 같이 들어 있음)
🔹 전체 = 모든 우편물을 글로 한 번에 보기

⑤ 탭 안의 작은 버튼들
🔹 각 분류 탭 안에 전체 / EMS / 등기/소포 서브탭 (EMS=E로 시작, 등기/소포=R·L·C로 시작). Details검색 탭만 예외
🔹 📋 등기번호 일괄 복사 — 지금 보이는 등기번호를 번호;번호; 형식으로 복사. GCSS 검색창에 그대로 붙여넣으면 한 번에 조회됩니다 (화면에 보이는 순서대로)
🔹 국가 ▾ — 도착국별 체크박스. 엑셀 필터처럼 원하는 나라만 보거나, 특정 나라만 빼기. 복사도 걸러진 것만 됩니다
🔹 Details검색 탭 — 종적 상세설명 안의 글자로 검색. [Item returned to sender] 같은 단축 버튼도 있어요

⑥ 결과 위쪽 도구
🔹 🔄 새로고침 — 방금 조회한 번호들을 그대로 다시 조회
🔹 🔍 등기번호로 탭 찾기 — 번호를 넣고 Enter 하면 그 번호가 있는 탭으로 이동 + 카드가 옅은 빨강으로 한 번 깜빡 (붙여넣을 때 공백 자동 제거)
🔹 동시 — 한 번에 동시에 조회하는 개수 (기본 10)
🔹 🗑 전체 삭제 — 입력칸과 결과를 모두 비움

클릭으로 할 수 있는 것
🔹 등기번호 클릭 — 복사
🔹 종적 줄 클릭 — 그 사이트 조회 페이지를 백그라운드로 엶 + 그 줄의 N 표시 해제
🔹 메모 영역 클릭 — 20자 이내로 메모 입력 (Enter 저장 / ESC 취소)

지우기·정리

🔹 [N뱃지 해제] 버튼 — 모든 N 표시를 한 번에 끄기
❔ 사용설명 ▼
⭐ 이 탭은? 계속 지켜봐야 할 우편물을 등록해 두는 곳입니다. [새로고침]을 누를 때마다 새 종적이 들어온 카드에 빨간 N 뱃지가 붙어, 무엇이 움직였는지 한눈에 보입니다.

① 등록하는 법
🔹 입력칸에 등기번호를 넣고 [+ 추가] (또는 Enter). 여러 개 가능 (줄바꿈·공백·쉼표·세미콜론 구분)
🔹 입력칸 아래 체크박스로 어느 탭에 넣을지 고름 (여러 탭 동시 가능, 안 고르면 '기타(탭분류X)' 탭으로 — 탭 분류를 안 한 항목이 모이는 기본 탭)
🔹 같은 번호를 다시 추가하면, 새로 고른 탭에만 합쳐집니다 (중복 등록은 안 됨)

② 탭으로 나눠 관리
🔹 [＋ 새 탭]으로 나만의 분류 탭을 만들 수 있어요 (예: 'VIP', '오늘 확인')
🔹 탭 이름 옆 × — 그 탭과 그 안의 우편물을 삭제 (다른 탭에도 들어 있는 우편물은 거기엔 남아요)
🔹 전체 탭 — 모든 탭의 우편물을 중복 없이 한 곳에. 여기서 카드 ×는 완전 삭제
🔹 탭 이동(드래그) — 카드를 마우스로 끌어 탭 버튼 위에 놓으면 그 탭으로 이동해요. 여러 개는 Ctrl/Shift+클릭으로 선택한 뒤 그중 하나를 끌면 한꺼번에. Ctrl 누른 채 놓으면 복사(원래 탭에도 남음). 특정 탭에서 이동하면 그 탭에서 빠지고(다른 탭 소속은 유지), 전체 탭에서 끌면 항상 복사예요 — 전체 탭엔 모든 우편물이 늘 있어야 하니까. 같은 이유로 전체 탭에 놓을 수도 없어요
🔹 탭 이름 형식: 이름 (우편물 수) · N — 새 종적 뜬 카드가 있으면 빨간 N 표시 (해당 카드가 맨 위로 올라옴). 예: 기타(탭분류X) (15) · N

③ 찾기·거르기
🔹 맨 위 🔍 검색 — 모든 탭을 통틀어 등기번호로 찾습니다(전역). 결과를 누르면 그 우편물이 있는 탭으로 이동하고 카드가 옅은 빨강으로 깜빡
🔹 탭바 아래 전체 / EMS / 등기·소포 — 우편 종류로 1차 거르기 (EMS=E로 시작, 등기·소포=R·L·C로 시작)
🔹 그 오른쪽 [뱃지 ▾] — 반송·정상배달 뱃지로 2차 거르기 (체크한 뱃지만 보임). 종류와 뱃지를 합쳐 원하는 것만 추려 볼 수 있어요

④ 카드에 보이는 것 (일괄조회와 거의 같음)
🔹 ePOST / GCSS / iCare 세 줄, 가장 최근에 움직인 줄이 굵게
🔹 등기번호 옆 파란 약호 = 도착국 (ePOST 기준)
🔹 카드 오른쪽 위 상태 뱃지 — 반송진행 → 반송도착 → 반송배달(갈수록 진해짐) / 정상배달(초록). 없으면 진행 중
🔹 GCSS·iCare 줄의 색 뱃지 = 행방조사 최근 단계 — 파랑 Q·청록 R·보라 SUM·Msg 중 최신, 셋 다 없으면 회색 NOT·NQ·NR. 종료(CLOSURE)는 숨김
🔹 줄 끝 빨간 N = [새로고침] 했을 때 그 사이트에 새 종적이 들어왔다는 뜻. 저절로 갱신되진 않으니 새로고침을 눌러야 합니다
🔹 카드 순서 — 갓 추가한 종목(조회 전) → N(새 종적) → 뱃지(반송·정상배달) → 나머지 순으로 묶고, 묶음 안에서는 최근 종적 순. 새로 추가하면 맨 위에 떠서 바로 메모를 달 수 있고, 새로고침하면 제자리로 갑니다

⑤ 버튼들
🔹 🔄 새로고침 — 관심목록 전체를 다시 조회. 진행 중에는 "조회 중 n/총개수"로 표시되고 다시 누르면 중지됩니다. 끝나면 완료 알림이 잠깐 떠요
🔹 N뱃지 해제 — 모든 N 표시 끄기
🔹 전체 삭제 — 관심목록 전부 비우기
